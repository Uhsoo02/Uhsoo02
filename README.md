## 🚀 Projects

### 🏥 HEALYX

> 국내 거주 외국인의 의료 서비스 이용을 돕는 Flutter 기반 애플리케이션

외국인 사용자가 언어 장벽으로 인해 겪을 수 있는  
의료 서비스 이용의 불편함을 줄이고자 개발한 팀 프로젝트입니다.

#### 주요 기능

- 텍스트, 음성 및 증상 아이콘을 활용한 병원 찾기
- 의료 문서 번역
- 예상 의료비 확인
- 사용자 간 의료 정보를 공유할 수 있는 커뮤니티
- 로그인, 회원가입 및 사용자 인증
- 한국어, 영어, 중국어 등 다국어 사용자 인터페이스
- 사용자 활동에 따른 앱 내 알림 제공

#### 담당 역할

**화면 퍼블리싱**

- 언어 선택 화면
- 메인 화면
- 병원 찾기 화면
- 로그인 및 회원가입 화면
- 아이디 및 비밀번호 찾기 화면

**REST API 연동**

- 로그인 및 비로그인 사용자 권한 분기
- 비밀번호 재설정
- 병원 찾기
- 커뮤니티
- 프로필 설정

**UI·UX 및 협업**

- 앱 내 알림 UI 직접 디자인
- Flutter와 Dart를 활용한 주요 화면 구현
- API 응답 데이터 처리 및 예외 상황 대응
- Git 브랜치와 Pull Request를 활용한 팀 협업
- 팀원들과 기능 요구사항 및 API 연동 방식 조율
- 기능 테스트와 오류 수정을 통한 서비스 완성도 개선

#### 성장 경험

HEALYX를 개발하면서 단순히 화면을 구현하는 것에 그치지 않고,  
외국인 사용자가 의료 서비스를 이용하는 과정에서 겪는 불편함을 살펴보며  
사용자 관점에서 필요한 기능과 화면 흐름을 고민했습니다.

또한 백엔드 API를 실제 화면과 연결하는 과정에서 데이터 구조와 인증 흐름을 이해하고,  
로그인 상태와 비로그인 상태에 따른 권한 분기 및 다양한 예외 상황을 처리하며  
문제를 해결하는 경험을 쌓았습니다.

- **Project Type:** Team Project
- **Role:** Frontend Developer
- **Tech:** Flutter, Dart, REST API
- **Collaboration:** Git, GitHub, Pull Request

### 🐟 Smart Fish Tank Control System

> IoT 하드웨어와 모바일 앱을 연동해 어항 환경을 자동으로 관리하는 시스템

센서를 통해 어항의 환경 데이터를 수집하고,  
사용자가 모바일 앱에서 어항 상태를 확인하고 장치를 관리할 수 있도록 제작한 팀 프로젝트입니다.

#### 주요 기능

- 센서를 활용한 어항 환경 데이터 수집
- 모바일 앱을 통한 어항 상태 확인
- ESP8266(NodeMCU) 기반 데이터 통신
- 어항 장치 제어
- 센서 데이터 저장 및 조회
- IoT 하드웨어와 모바일 앱 간 데이터 전달

#### 담당 역할

- Flutter를 활용한 프론트엔드 UI 구현
- 하드웨어 센서 연동
- ESP8266(NodeMCU) 기반 통신 기능 구현
- 센서 데이터 수집 및 전달 구조 구현
- 모바일 앱을 통한 어항 장치 제어 기능 구현
- 센서 데이터 저장 및 조회 기능 구현
- GitHub를 활용한 팀 협업
- 기능 통합 과정에서 발생한 오류 확인 및 수정

#### 성장 경험

스마트 어항 프로젝트를 통해 하나의 서비스가 동작하기 위해서는  
화면뿐만 아니라 센서, 통신 모듈, 데이터 처리 과정이  
유기적으로 연결되어야 한다는 것을 배웠습니다.

직접 하드웨어 센서와 ESP8266 통신을 구현하고 모바일 앱과 연동하면서,  
IoT 센서에서 수집된 데이터가 사용자 화면에 전달되는 전체 흐름을 경험했습니다.

또한 팀원들과 역할을 나누고 각 기능을 통합하는 과정에서  
기능 간 연결과 협업의 중요성을 배웠습니다.

- **Project Type:** Team Project
- **Role:** Frontend & Hardware
- **Tech:** Flutter, Arduino, ESP8266(NodeMCU)
- **IDE / Tool:** Android Studio, GitHub
